# B站通知清理工具

这是一个用于删除B站（哔哩哔哩）通知的Python工具。

## 特点

- 支持删除点赞、回复和@我三种通知类型
- **扫码登录**：自动打开浏览器，用户扫码即可登录
- **可视化操作**：可以看到浏览器中的删除过程
- 显示详细的删除进度和结果

## 环境要求

- Python 3.6+
- Chrome 浏览器
- selenium 和 webdriver-manager 库

## 安装依赖

```bash
# 进入项目目录
cd 目录路径

# 创建虚拟环境（推荐）
python -m venv .venv

# 激活虚拟环境（Windows）
.venv\Scripts\activate

# 安装依赖
pip install selenium webdriver-manager
```

## 使用方法

```bash
# 运行脚本
.venv\Scripts\python.exe delete_bilibili_notifications.py
```

运行后：

1. 浏览器会自动打开B站首页
2. 在浏览器中点击右上角【登录】按钮
3. 使用手机B站APP扫码完成登录
4. 登录成功后回到终端按回车键继续
5. 选择要清理的通知类型（默认全部三种）
6. 脚本自动开始清理通知

## 注意事项

1. 请确保已安装 Chrome 浏览器
2. 首次运行会自动下载 ChromeDriver，需要网络连接
3. 如果网络无法下载 ChromeDriver，请手动下载并放到 PATH 中
4. 不要过于频繁地运行脚本，避免触发B站的反爬虫机制
